# Fire Pro Retail Canonical Reconstruction

This branch is a clean reconstruction authority for Fire Pro Wrestling World retail behaviour.

**It does not inherit any prior runtime as canon.** Prior Notion pages, candidate ZIPs, assemblers, viewers and recovered runtimes are historical/quarantine material only. They may suggest where to look, but they cannot establish a retail fact.

The project is currently in **SOURCE_CONSOLIDATION**. Runtime/viewer construction is mechanically disabled until the canonical evidence dataset says otherwise.

## Authority order

1. Exact matching retail `Assembly-CSharp.dll` bytes and direct code/data extraction.
2. Raw observational recorder captures whose metadata pins the same DLL hash.
3. Raw packed retail animation/data resources used by the matching build.
4. Decode-vault material only when its underlying source provenance is revalidated.
5. Human visual observation as a confirmation layer, never as a substitute for missing ownership/data semantics.

Synthetic fixtures are regression tools only. They can never create a retail fact.

Run `python tools/prove_no_assumptions.py` before any canonical commit or release work.
